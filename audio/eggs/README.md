# Easter-egg clips

Optional meme sounds played by `js/eggs.js`. Save each one here with exactly this name; a missing file is skipped.
How often each fires, and which games count as hit / dodge / catch / run / blackout, is set in the tables at the top of `js/eggs.js`.
